## Accurate description

This is a source-backed local portfolio prototype that demonstrates the tool
building, workflow standardization, testing, documentation, and maintainability
parts of the role. It provides a simple integration boundary through JSON,
health, refresh, Markdown, and `.ics` outputs. It is not a production CoreWeave
plug-in and does not prove stakeholder discovery, internal deployment,
cross-functional adoption, or business impact.
